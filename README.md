# 📝 To-Do List

A simple and responsive **To-Do List web application** that helps users manage their daily tasks easily.

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📱 Responsive design
* 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
